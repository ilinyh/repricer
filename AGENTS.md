# AGENTS.md

Краткие правила для ИИ-агентов, работающих в этом репозитории.

## Команды

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -U pip pytest
.venv\Scripts\python -m pytest
```

## Структура

- `src/repricer/core/` — чистое ядро расчёта. Без ввода-вывода, без обращения к часам, без БД.
  Даты и параметры передаются аргументами.
- `src/repricer/adapters/` — источники учётных данных и клиенты площадки. Новый источник —
  новый адаптер, ядро не меняется.
- `emulator_wb/` — отдельный сервис-эмулятор Wildberries. Общается с репрайсером только по HTTP.
- `tests/` — тесты. Контрольные примеры из приложения А ТЗ должны сходиться один в один.

## Соглашения

- Деньги — целые копейки. Проценты и коэффициенты — `Decimal`. Плавающая точка запрещена.
- Дата расчёта — параметр. Не использовать `datetime.now()` внутри ядра.
- Коммиты атомарные, без сквоша.
- Все решения, принятые там, где ТЗ молчит, фиксируются в `PLAN.md` и README (раздел «Допущения»).
